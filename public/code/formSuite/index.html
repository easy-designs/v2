Form Suite

General Information

Purpose
This is a generic form suite which allows for validation based on the public XHTML 1.0 Strict+ DTD (unavailable in the surviving archive). It also include facilities for faux-progress bars on file upload. More details to come.
Current Version
1.0 (18 September 2005)
Requirements
For a valid page, use of the XHTML 1.0 Strict+ DTD (unavailable in the surviving archive) is required

Use

Just include the file.
